Region proxies — for geo-locked channels

Geo-locked channels check your IP's country. Assign a proxy located in that country and its channels auto-route through it. One line per country — Country = proxy URL — using the sidebar country name.

SOCKS needs PySocks on the server (pip3 install PySocks). A proxy must be in the channel's own country to unlock it.
